02 — About

Software, built with care.

I’m Anid Sadiku, a second-year computer science student at UBT in Kosovo, working toward a career as a full-stack developer. I’m interested in the whole path of an application: from a first sketch to a working interface, and the systems and data behind it.

The five projects on this site are working prototypes you can click through. Two are mobile app concepts, a banking app for freelancers and a recovery tracker; three are web projects, a furniture shop, an electronics store in English and Albanian, and a carbon-data dashboard. The dashboard, Northwind, is full-stack: a Node.js API, a SQL database and a Python analytics service run behind it. The other four run in the browser.
